# Support

Report problems at https://github.com/KubaOchremiak/VSC_Maister_plugin/issues.

Include the Maister Lens version, VS Code version, OS, local/remote workspace type,
Workspace Trust status, theme name and steps to reproduce. For rendering issues,
include a screenshot and say whether the view is built-in or a hosted HTML artifact.
Remove credentials and private project content before sharing logs or task fixtures.

If no tasks appear, open the folder containing `.maister/tasks`, confirm task folders
contain `orchestrator-state.yml`, and run **Maister: Refresh**. To restore the sidebar
arrangement, run **Views: Reset View Locations**.

For local installation and known limitations, see
[README](https://github.com/KubaOchremiak/VSC_Maister_plugin#readme).
